# 2027 Calendar Planner

A React and TypeScript weekly planner split into three four-month periods.

## Run locally

Requires Node.js 20.19+ or 22.12+.

1. Run npm install.
2. Run npm run dev.
3. Open the local address printed by Vite.

The app saves automatically to local storage in the current browser.

## Features

- Editable period goals and outcomes.
- Weekly sprint plans, contests, revision, job applications, health, notes, and work fields.
- Click any date to add a daily note.
- Search the selected period.
- CSV export and JSON backup/restore.
- Responsive layout and print view.
- Local browser persistence.
